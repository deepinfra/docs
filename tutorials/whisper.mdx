[Whisper](https://github.com/openai/whisper) is OpenAI's speech recognition model. Given an audio file, it produces transcribed text with per-sentence timestamps. DeepInfra hosts both Whisper and several other speech recognition models, all reachable through the same API.

Browse [all speech recognition models](https://deepinfra.com/models/automatic-speech-recognition).

## Models

| Model | Notes |
|-------|-------|
| `openai/whisper-large-v3` | Best accuracy |
| `openai/whisper-large-v3-turbo` | Faster, near-large-v3 quality |
| `Qwen/Qwen3-ASR-1.7B` | Small and fast |
| `Qwen/Qwen3-ASR-0.6B` | Smallest |
| `nvidia/Nemotron-3.5-ASR-Streaming-Multilingual-0.6b` | Streaming, multilingual |
| `mistralai/Voxtral-Small-24B-2507` | Audio-understanding alternative |
| `mistralai/Voxtral-Mini-3B-2507` | Smaller audio-understanding alternative |

Whisper produces per-sentence timestamp segmentation.

## Example

<CodeGroup>

```javascript JavaScript
import { AutomaticSpeechRecognition } from "deepinfra";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const client = new AutomaticSpeechRecognition(
  "openai/whisper-large-v3",
  "$DEEPINFRA_TOKEN"
);

const response = await client.generate({
  audio: path.join(__dirname, "audio.mp3"),
});

console.log(response.text);
```

```bash cURL
curl -X POST \
    -H "Authorization: Bearer $DEEPINFRA_TOKEN" \
    -F audio=@audio.mp3 \
    'https://api.deepinfra.com/v1/inference/openai/whisper-large-v3'
```

</CodeGroup>

## Supported formats

- `mp3`
- `wav`
